# Instrucciones para agentes

Si este repositorio se está preparando en una máquina Omarchy nueva, primero ejecuta `./setup-omarchy.sh --dry-run` y explica las acciones previstas. Solo tras confirmación, ejecuta `./setup-omarchy.sh`; aplica los cambios Hyprland con `--apply-hyprland` únicamente si el usuario lo solicita. Usa `README.md` para el flujo completo de réplica y `HYPRLAND-SETUP.md` como fuente de verdad para integrar Hyprland. Nunca copies claves Gemini/OpenRouter ni archivos de estado efímero entre equipos.
